# IT Help Desk Ticketing Lab

## Project Overview
This project simulates an entry-level IT Service Desk environment. It focuses on troubleshooting technical issues, managing support tickets, documenting resolutions, and following professional IT support workflows.

## Objectives
- Practice diagnosing common IT support issues.
- Learn ticket prioritization, escalation, and documentation.
- Develop clear communication with end users.
- Build foundational troubleshooting and security awareness skills.

## Tools
- GitHub for project documentation and ticket tracking.
- GitHub Issues for simulated support tickets.
- Browser-based research and troubleshooting tools.

## Project Status
In progress — environment setup.

## Disclaimer
All users, incidents, and company information in this project are fictional. This is a training simulation, not professional work experience.
